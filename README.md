## 使用方式

1. 點上方任一連結（首次需接受課程 repo 邀請並登入 GitHub）
2. 每個任務：把 markdown 中的自然語言描述貼給 Gemini（免費版即可）→ 把生成的程式碼貼進空 cell → 執行 → 觀察結果
3. 參考程式碼已附在各任務下方——先自行生成再比對
